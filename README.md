# 阈光之旅 (Threshold Light Journey)

一个交互式2D横版艺术项目，灵感来自《地狱边境 (LIMBO)》和《INSIDE》，使用摄像头手势控制进行游戏。

## 🎮 项目概述

主角从昏睡中醒来，身处一个幽闭、抽象的地铁站环境。玩家通过手部姿势（摄像头捕捉）控制角色探索这个黑白剪影风格的世界。

### 核心特性

- 🎨 **黑白剪影艺术风格**：高对比度的视觉呈现，营造孤独与静谧的氛围
- 👋 **手势控制**：使用MediaPipe进行实时手势识别，伸出左右手控制角色移动
- 💡 **动态光照系统**：地铁经过时的真实光影效果，照亮角色并产生阴影
- ✨ **粒子效果**：光束中飘舞的灰尘粒子，增强场景真实感
- 🎬 **流畅动画**：角色行走、静止状态的平滑过渡

## 🚀 快速开始

### 1. 克隆项目

```bash
git clone <repository-url>
cd slot-machine
```

### 2. 启动项目

由于使用了MediaPipe和摄像头，需要通过HTTP服务器运行：

**方法一：使用Python**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**方法二：使用Node.js**
```bash
npx http-server -p 8000
```

**方法三：使用VS Code Live Server**
- 安装Live Server扩展
- 右键点击`index.html` → "Open with Live Server"

### 3. 访问网站

在浏览器中打开：`http://localhost:8000`

> ⚠️ **注意**：需要允许浏览器访问摄像头权限

## 🎯 如何游戏

### 手势控制

- **向左移动**：伸出左手，食指指向屏幕左侧
- **向右移动**：伸出右手，食指指向屏幕右侧
- **停止移动**：收回手势

### 键盘控制（备用）

如果摄像头不可用，可以使用键盘控制：
- `←` 或 `A`：向左移动
- `→` 或 `D`：向右移动

### 调试模式

在URL后添加`#debug`可查看调试信息：
```
http://localhost:8000#debug
```

### 参考作品

- **《地狱边境 (LIMBO)》**：高对比度黑白剪影风格
- **《INSIDE》**：细腻的灰度层次和光影运用

### 核心视觉元素

1. **角色**：简化的小男孩剪影，具有基础人体结构
2. **场景**：破旧的椅子、地铁闸机窗口
3. **光照**：周期性经过的地铁带来的动态光源
4. **粒子**：光束中的漂浮尘埃

## ⚙️ 技术细节

### 光照系统

- 地铁每隔 **14-20秒**（随机）经过一次
- 光照持续 **5秒**，分为三个阶段：
  - **接近阶段**（1秒）：光线由远及近逐渐增强
  - **全亮阶段**（2.5秒）：光线达到最强
  - **衰减阶段**（1.5秒）：光线逐渐减弱消失

### 手势识别

- 使用MediaPipe Hands进行手部关键点检测
- 分析食指指向方向判断移动意图
- 200毫秒的持续时间阈值防止误触
- 置信度阈值：0.6

### 角色动画

- **Idle**：静止状态
- **Walking Left**：向左行走（4帧循环）
- **Walking Right**：向右行走（4帧循环）
- 平滑的加速/减速效果

## 🐛 常见问题

### Q: 摄像头无法启动？
A: 请确保：
1. 浏览器有摄像头权限
2. 使用HTTPS或localhost访问（HTTP可能被阻止）
3. 没有其他应用占用摄像头

### Q: 手势识别不准确？
A: 建议：
1. 确保光线充足
2. 手部完整出现在摄像头视野内
3. 手势保持清晰、明确的指向

### Q: 性能卡顿？
A: 尝试：
1. 关闭其他标签页
2. 降低浏览器缩放比例
3. 使用性能更好的设备
